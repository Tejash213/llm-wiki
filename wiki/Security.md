## Summary
Security is a required concern within the orchestration architecture, ensuring safe data connectivity, agent deployment, and interface management across integrated systems.

## Key Points
- The orchestration layer must enforce security controls when connecting to systems of record and content repositories via APIs.
- Security considerations include access control, data governance, and protection of sensitive extracted information used by agents.
- Secure design enables enterprises to automate workflows while maintaining compliance and protecting financial and tenant data.
