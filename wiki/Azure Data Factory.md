## Summary
Azure Data Factory is cited as a tool for building data pipelines when clients are using Microsoft Azure as part of the platform's integration strategy.

## Key Points
- Used to construct ingestion and extraction pipelines for Azure-hosted clients.
- Fits into the architecture's API-first integration approach and respects data locality rules.
- One of the practical mechanisms for connecting external systems to the central platform.
