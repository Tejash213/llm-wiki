## Summary
The capability to invoke AI directly within existing applications—for ad-hoc tasks via UI elements or as continuous background processes triggered by events.

## Key Points
- Enables AI invocation from buttons or UI affordances for on-demand assistance.
- Supports background processes that run continuously or trigger on specific events using patented triggers.
- Integrates tightly with the centralized data layer and orchestration layer for context-aware actions.
