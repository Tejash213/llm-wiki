## Summary
The [[AI Interview Agent]] is a Python-based system deployed on [[Microsoft Azure]] using GPT-4o, designed to conduct mock interviews with synthesized speech and dynamic question generation.

## Key Points
- Features a web interface with a digital avatar, speech-to-text, and role-specific question generation.
- Prototype relies on manual input and introduces a new data structure for departments, which is discouraged.
- Video avatar is costly; voice-only version is recommended for cost management.
- Should be integrated into core workflows, not used as a standalone tool.
