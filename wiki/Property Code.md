## Summary
A property code is an example of structured metadata from systems of record (like Yardi) used to link documents, projects, leases, work orders, and tenant information.

## Key Points
- Property codes act as connective metadata that provide a unified view of all activities related to an asset.
- When applied consistently to unstructured content, property codes enable intelligent search and agentic operations around a property.
- They are foundational to data mastery and platform connectivity strategies for real estate operations.
