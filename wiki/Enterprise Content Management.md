## Summary
Enterprise content management refers to systems like Box and SharePoint that store unstructured documents and media, requiring API connectivity and metadata to be useful for AI-driven workflows.

## Key Points
- Integration via API is necessary but not sufficient; consistent metadata tagging is required to unlock the value of content repositories.
- When linked to systems of record, enterprise content becomes actionable and searchable by agents and models.
- Content management systems serve as the source for document uploads that can trigger agentic workflows and document extraction processes.
