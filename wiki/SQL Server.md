## Summary
SQL Server is described as the current database foundation for the platform, with separate on-premise instances per client and programmatic normalization features.

## Key Points
- Serves as the platform's base database technology in the described architecture.
- Used with separate on-premise instances for each client to meet data locality or compliance needs.
- The architecture's design allows future interface or migration to other technologies like Cosmos DB.
