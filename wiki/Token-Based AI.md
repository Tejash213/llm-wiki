## Summary
A cost model for AI consumption where compute and model usage are billed based on tokens processed; the architecture adopts strategies to minimize token usage and manage cost.

## Key Points
- Token consumption is a primary cost driver for AI usage and requires architectural controls.
- Techniques like pre-vectorized indexes and AI-generated digests reduce token usage for routine queries.
- Solution architects must design agents to prefer indexed resources to keep costs manageable.
