## Summary
AI Model refers to the underlying technology used to process data and generate results, including basic [[LLMs]], machine learning, and specialized [[AI Agents]].

## Key Points
- Basic [[LLMs]] process user data and return results.
- Stand-alone agents add logic and customization to basic models.
- Multiple agents can collaborate in workflows, using different models for complex tasks.
