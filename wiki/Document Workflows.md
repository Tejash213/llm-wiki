## Summary
Document Workflows are [[Agentic AI|AI]]-driven processes that classify, extract, and route documents to specialized [[AI Agents]], enabling structured outputs and [[Automation]] within organizational contexts.

## Key Points
- Document profiler flow attaches files, classifies type, and routes to extractor agents.
- Lease extractor agent generates lease language and structured outputs.
- Workflows handle timing, event ordering, and updates when new data arrives.
- Exception management is implemented for sensitive content (e.g., password mentions).
