## Summary
[[Text-to-API]] is an emerging [[Agentic AI|AI]] technology that converts natural language instructions into API calls, enabling automated system interactions and process execution.

## Key Points
- [[Text-to-API]] allows natural language to generate API calls with appropriate payloads for various systems.
- The instigating text can be generated by a person or another [[Agentic AI|AI]] system, enhancing automation.
