## Summary
An AI agent capable of executing tasks within the system, such as adding notes to project cases or performing updates based on user instructions.

## Key Points
- Executes discrete actions in the operational system based on natural-language or structured instructions.
- Enables end-to-end automation when combined with planning and orchestration agents.
- Requires secure integration and governance to ensure appropriate permissions and auditability.
