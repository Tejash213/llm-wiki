## Summary
CAS jobs are standardized roles or tasks within an organization, which can be algorithmically defined and compared using [[AI Adoption]].

## Key Points
- Can be analyzed for overlaps and gaps using [[AI Adoption]].
- Algorithmic CAS jobs use "if this, then that" logic.
- Integration with [[Job Descriptions]] and [[Standards]] streamlines workflows.
