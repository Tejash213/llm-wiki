## Summary
[[Security and Permissions]] ensure that [[AI Agents|Agents]] operate within defined access control contexts, enforcing least privilege and secure propagation of user or service-account permissions throughout the system.

## Key Points
- [[Search Agent]] indexes and retrieves data only within the user's access context.
- [[Action Agent]] inherits the same permission model.
- Access checks are enforced at search and action layers; dual modes for invocation.
