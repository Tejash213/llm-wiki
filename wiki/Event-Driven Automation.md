## Summary
Event-driven automation uses data events, approvals, or file attachments to trigger [[Multi-Agent Workflows|AI workflows]] and background services, expanding beyond traditional chat-based prompts.

## Key Points
- [[AI Solutions Inventory]] are triggered by events such as file attachments or workflow approvals.
- Enables automation of processes like deal profiling, [[Azure Document Intelligence]], and [[Construction Operations]].
- Supports rapid, resilient deployment and [[AI Integration]] across enterprise workflows.
