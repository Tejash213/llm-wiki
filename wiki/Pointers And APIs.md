## Summary
Design principles that prefer referencing external data sources via pointers and APIs rather than full import, preserving data locality and reducing unnecessary complexity.

## Key Points
- The correct approach for large external stores (e.g., IoT sensor databases) is to create pointers and derivative values rather than importing raw data.
- APIs serve as the primary gateway for integration and enable middleware to connect diverse platforms.
- Supports scalable architectures and simplifies governance by keeping data in native systems where appropriate.
