## Summary
[[User-Context Data]] includes information about the user's environment, role, and current activities, which can be passed to [[AI Model]]s for enhanced relevance.

## Key Points
- Contextual data includes screen viewed, user role, open [[Task]]s, permissions, and identifying information.
- Improves [[Agentic AI|AI]] output by providing relevant context.
- Reduces need for manual data entry.
