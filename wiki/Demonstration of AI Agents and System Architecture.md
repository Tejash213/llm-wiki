## Summary
Overview of the company's AI agent ecosystem and how different agents interoperate with a unified data layer to support analytics, search, actions, planning, and domain expertise.

## Key Points
- The architecture includes specialized agents (Understanding, Insight Navigator, Search, Action, Planning/Orchestration, Expert Agents) coordinated via a structured data layer.
- Agents provide capabilities ranging from schema understanding and semantic search to task execution and workflow orchestration.
- Integration with a unified data model differentiates the platform from competitors by enabling both generalist and specialist AI-driven operations.
