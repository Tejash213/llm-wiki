## Summary
The document lists representative use cases showing when simple agents are sufficient and when planner-executor orchestration is required for scale and complexity.

## Key Points
- Small use case: "Profile these four leases and add them to the tenant file" — straightforward, single-shot work.
- Large use case: "Review 4,000 records for data quality, normalize via three steps each" — requires orchestration, memory, and coordination.
- Large-scale migrations (e.g., 100,000 documents) demand planning agents plus execution agents to manage parallelism, retries, and consistency.
